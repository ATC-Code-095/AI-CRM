# 业务模块规格

每个模块一个文件。结构固定：

1. **目标 / 非目标**
2. **权限点**
3. **用例（Given/When/Then）**
4. **API**
5. **业务规则**
6. **UI 要点**
7. **测试清单**
8. **依赖**
