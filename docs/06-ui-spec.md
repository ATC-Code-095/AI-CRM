# 06 UI / UX 规格

## 1. 信息架构

```
登录
└── 应用壳（左侧导航 + 顶栏）
    ├── 工作台 Dashboard
    ├── 获客（线索 / 营销活动 / 公海查重）
    ├── 客户（客户 / 联系人）
    ├── 销售（商机 / 报价 / 产品价格 / 跟进 / 日历 / 跟进计划）
    ├── 履约（合同 / 服务工单）
    ├── 分析（报表中心 / 目标 / 销售赋能）
    ├── 协作（审批 / 通知中心）
    └── 管理（数据字典 / 组织 / 用户 / Webhook / Token / API 文档 / 审计 / 设置）
```

## 2. 布局

- 左侧导航 `236px`，可折叠 `72px`（≥768）；菜单按 获客 / 客户 / 销售 / 履约 / 分析 / 管理 分组
- 顶栏 `56px`（浅色，品牌蓝点缀）：面包屑、⌘K 命令面板、快速新建、待办铃、主题、用户菜单
- **`<768` 手机 IA：** 顶栏 52px + 底部 Tab（工作台/客户/商机/跟进/我的）；次级功能进汉堡抽屉
- 内容边距 `20px`（移动 `12px`），卡片间距 `16px`（移动 `12px`）
- 列表页：`标题` → `筛选条` → `工具栏` → `表格/看板`；移动为卡片列表 + 顶部简化筛选
  （`components/MobileCardList.tsx`：线索/客户/联系人/商机在 `<768` 自动降级为卡片，不再横向滚动表格）
- 详情页：`头信息卡` → `Tab`；移动 Tab 可横滑
- 断点：`≥1280` 桌面；`768–1279` 平板/小桌面；`<768` 手机 IA；`<375` 仍保证核心写路径
- 看板拖拽仅 ≥768；`<768` 降级为「阶段筛选 + 列表改阶段」

## 3.0 手机端卡片列表与「我的」

- `<768`：`ErpTable` 网格自动切换为 `MobileCardList`（标题 / 状态标签 / 副标题 / 两列字段 / 操作区），
  卡片整块可点进详情，操作按钮区阻止冒泡。
- 底部 Tab 固定 `工作台 / 客户 / 商机 / 跟进 / 我的`（`/me`）：账号信息、语言、深色模式、主题色、
  离线草稿同步与清空、常用管理入口、退出登录。
- 离线草稿来自 `utils/offlineDraft.ts`：断网新建跟进自动暂存，联网后可在「我的」一键同步。

## 3.1 功能块（区域功能块统一宽高）

所有仪表盘/报表区域一律使用栅格容器，禁止再写死 `Row/Col` 宽度：

```html
<div class="crm-grid crm-cols-3 crm-h-md">
  <Card ... />   <!-- 同行 3 等宽、统一 320px 高 -->
  <Card ... />
  <Card ... />
</div>
```

| class | 含义 |
|-------|------|
| `crm-grid` | 功能块栅格容器（`gap: 16px`，`align-items: stretch`） |
| `crm-cols-2/3/4/5` | 同行 2/3/4/5 等宽；`≤1180px` 自动降为 2 列，`≤860px` 单列 |
| `crm-h-sm / crm-h-md / crm-h-lg` | 行高统一 `132 / 320 / 392px` |
| `crm-h-tile` | 入口大卡行高 `244px` |
| `crm-h-auto` | 按内容高度（仅用于说明类块） |
| `crm-panel-fixed[.crm-panel-sm]` | 通栏单块固定高度（标准/紧凑） |
| `crm-kpi` | 指标块（`132px`，左侧语义色条 + 渐变底） |
| `.crm-reports .ant-card` | 报表页所有功能块统一 `360px`，超出部分块内滚动 |

规则：
- **同一行必须等高**（由栅格保证）；同一类块跨页面高度一致（统一走上面的 token）。
- 块内内容超出时**块内滚动**，不允许撑高页面（商机看板列同理）。
- 列表页/详情页的功能块不强制固定高度，但同一行等高。

## 3.1.1 列表视图（服务端保存 + 团队共享）

- 每个 ErpTable 列表都可「保存当前视图」：记录筛选、列顺序、列显隐、列宽；
- 视图写入 **用户级偏好** `PUT /preferences {key: list_views.<列表>}`（`Setting.scope=USER`），
  换设备 / 清缓存后仍在；服务端不可用时自动回落到 localStorage 并在恢复后迁移；
- 勾选「共享给团队」会同时写入 `shared.list_views.<列表>`，同事在「视图」下拉里以
  「共享 · 名称 @ 同事」只读复用（`GET /preferences/shared`）。

## 3.1.2 关注（星标）

- 客户 / 商机 / 线索详情页标题右侧星标按钮，数据写入用户偏好 `stars`；
- 工作台「我的关注」卡片汇总展示（类型标签 + 名称 + 一键取消），可在「自定义工作台」里隐藏。

## 3.2 表格列宽自适应

- 报表与分析表格统一用 `components/AutoFitTable.tsx`（内部 `utils/autoFit.ts`）：
  1. 用 canvas 按真实字体测量表头与样本单元格宽度；
  2. 列定义里的 `width` 作为**下限**，保证文字不换行、金额不折行；
  3. 富余宽度在列间均摊（触顶 `maxWidth` 的列不再增长），列宽合计铺满容器；
  4. 内容总宽超过容器时改为横向滚动，而不是把列压扁；
  5. 纯数字列自动右对齐（`tabular-nums`）。
- 列表页（Infor 风格网格）继续用 `ErpTable`：固定列宽 + 拖拽调宽 + 列宽记忆。
- 禁止对表格使用 `:nth-child` 全局列宽（会污染报表表格）。

## 3.3 主题色

- 主题预设（企业蓝 / 青绿 / 紫罗兰 / 暖橙 / 石墨）**同时写入品牌色阶** `--crm-brand-400/500/600/700`，
  保证按钮、菜单选中态、欢迎横幅、报表入口卡、KPI 色条一起换色。
- 实现见 `hooks/useUiTheme.ts` 的 `ACCENT_PRESETS` / `applyAccent()`；禁止只改 `--crm-accent`。

## 3.3.1 侧栏菜单搜索

- 侧栏品牌区下方常驻「搜索菜单…」输入框：命中菜单名 / 英文键 / 拼音关键词（`navigation.tsx` 的 `keywords`），
  命中项扁平展示并带分组提示，点击后自动清空搜索词；抽屉（移动端）同样支持。
- 菜单项超过 30 条时的必备能力，避免长侧栏靠滚动找人。

## 3.4 命令面板（⌘K / Ctrl+K）

- 顶栏常驻入口 `搜索或跳转… ⌘K`，一屏完成：**快捷新建 / 最近访问 / 导航 / 搜索结果**。
- 键盘：`↑↓` 选择、`Enter` 打开、`Esc` 关闭；搜索走 `GET /search`。
- 快捷新建通过 `utils/quickCreate.ts` 跨页唤醒列表页的新建弹窗（`crm:create` 事件 + sessionStorage 兜底）。

## 3.4.1 AI 助手（全局抽屉）

- 顶栏「AI」按钮 / ⌘K 输入「AI 助手」打开；在详情页打开会自动带入当前对象。
- 四种能力：**生成摘要**（商机/客户/线索）、**下一步建议**、**风险预警**（低/中/高）、**销售教练**（要点 + 话术）。
- 每个结论可「复制」或「生成跟进」——后者直接调用 `POST /activities` 落一条 NOTE 跟进，形成「AI 建议 → 可执行动作」闭环。
- 接口：`POST /ai/summarize`、`POST /ai/suggest-next`、`POST /ai/risk`、`GET /reports/sales-coach/:id`。

## 3.4.2 键盘快捷键

| 键 | 作用 |
|----|------|
| `⌘/Ctrl + K` | 命令面板（搜索 / 跳转 / 快捷新建） |
| `?` | 快捷键帮助（顶栏用户菜单也有一项） |
| `g` → `h/l/a/o/c/r/t/n` | 依次跳转 工作台/线索/客户/商机/日历/报表/跟进/通知 |
| `c` | 快捷新建 |
| `Esc` | 关闭弹窗 / 抽屉 |

实现要点：焦点在 `input/textarea/select/contenteditable` 内时全部快捷键失效；`g` 组合键 1.5s 内有效。

## 3.4.3 阶段门禁（Validation Rules）

- 内置规则按阶段 code 生效，`PipelineStage.requiredFields`（`needAmount` / `needCloseDate` /
  `needNextStep` / `needQuote` / `needContact`）可覆盖或追加：

  | 阶段 | 要求 |
  |------|------|
  | 需求确认 DISCOVERY | 商机金额 |
  | 方案/报价 PROPOSAL | 商机金额、预计成交日、至少一条报价 |
  | 谈判 NEGOTIATION | 商机金额、预计成交日、下一步动作、客户联系人（决策链） |
  | 赢单 WON | 商机金额 |

- 缺失时返回 `42200`，消息一次性列出**全部**缺失项（如「推进到「谈判」前需补齐：下一步动作、客户联系人（决策链）」）；
- 商机详情页改阶段失败时在顶部常驻警示条（可关闭），看板拖拽/批量改阶段走 toast；
- 批量改阶段额外返回 `firstError`，前端可提示失败原因。

## 3.5 商机看板拖拽

- 列 = 阶段，卡片可拖拽换阶段；落下前二次确认（对齐 §5.2 签名交互）。
- 每列默认展示 8 张卡，其余「点击展开」；列高固定 `560px`，列内滚动。
- 卡片展示负责人（`GET /boards/pipeline` 附带 `owner`）与预计成交日；列表视图含负责人列。
- 工具栏支持 **负责人筛选**（走后端 `ownerId`）与 **关键词筛选**（名称/客户/负责人，前端过滤）。

## 5. 关键页面

### 4.8 跟进计划（Cadence）

- `/cadence`：用「第 N 天」编排电话 / 拜访 / 邮件 / 任务步骤，一键为多条线索或客户排期；
- 计划存用户偏好 `cadence.plans`（跨设备），勾选「共享给团队」写入 `shared.cadence.plans`，
  同事在「团队共享计划」只读复用；无需数据库迁移；
- 启动计划调用 `POST /activities/batch`（一次最多 200 条，事务写入，线索自动 +5 分/条上限 100），
  生成的活动 `source=CADENCE`、状态 `PLANNED`，直接出现在「日历 / 跟进」与工作台待办；
- 入口：侧栏「销售 → 跟进计划」；预设建议：新线索 3 步破冰 / 报价后 3 步跟进 / 续约 3 步。

### 4.9 日历（月视图 + 议程）

- `/calendar`：左侧月视图（周末底色、今天高亮、单元格显示前 3 条 + 「+N」），右侧选中日「日程」面板；
- 数据源 = 跟进活动（`/activities?from&to`）+ 会议纪要（`/meetings`），支持 全部 / 跟进 / 会议 过滤与 月视图 / 议程 切换；
- 两个功能块同行等高（470px），日程面板内部滚动，避免 80+ 条日程把页面撑长；
- 入口：侧栏「销售 → 日历」、首页快捷动作「日程日历」、「我的 → 快捷入口」。

### 5.0 通知中心与批量操作

- 顶栏铃铛抽屉只看最新 20 条；`/notifications` 为完整通知中心：全部 / 未读 / 审批 / 提醒 四类筛选、
  分页、单条已读、全部已读，点击按 `entityType` 跳到客户/线索/商机/报价/合同/工单/审批。
- 列表页多选：勾选**不得**触发行点击进详情（`ErpTable` 已在勾选框阻止冒泡）。
  联系人批量操作：设为主联系人（同客户唯一）/ 导出所选 CSV / 批量删除（二次确认）。
  客户批量操作：分配负责人 / 导出所选 CSV / 批量删除（有开放商机或合同的客户自动跳过并回报数量，
  接口 `POST /accounts/batch-assign`、`POST /accounts/batch-delete`）；线索批量操作：批量分配 + 导出所选。

### 5.0.1 快捷新建

- 顶栏「＋ 快捷新建」支持 线索 / 客户 / 联系人 / 商机 / 跟进 五种。
- 关联对象一律选择而非手输：商机与联系人用客户下拉，跟进用「客户/线索/商机」搜索选择器
  （`components/EntityPicker.tsx`）。

### 5.1 工作台
今日待办、我的管道漏斗、本月目标进度、快捷新建、团队动态。

### 5.2 商机看板（签名交互）
- 列 = 阶段；卡片：名称、客户、金额、赢率、预计成交、负责人
- **拖拽换阶段** → 确认抽屉 → `PATCH /stage`
- 支持看板/列表切换、按负责人筛选

```mermaid
flowchart LR
  A[看板列] -->|拖拽| B[确认抽屉]
  B --> C[PATCH /stage]
  C --> D[刷新看板]
```

### 5.3 线索转化向导（Modal 分步）
1. 新建客户 / 关联已有客户  
2. 补充联系人/客户字段  
3. 可选创建商机  
4. 确认 → 跳转客户详情  

### 5.4 客户 360
头：名称、等级、负责人、指标卡。  
Tab：概览 / 联系人 / 商机合同 / 协作服务。
- 联系人 Tab：人脉列表 + 直接新增（姓名/职位/决策角色/手机/邮箱），保存后刷新 Tab 计数；
- 商机合同 Tab：统一 2×2 栅格 —— 基本信息 / 决策链（Buying Committee）/ 商机 / 合同 / 回款 / 工单，
  每个功能块同为 320px 等高、块内滚动。

### 5.5 报价编辑
左产品搜索双击加入；右行项目（数量/单价/折扣/金额）；折扣超阈值 Alert「需审批」；底部固定合计。

### 5.6 审批中心
Tab：待我审批 / 我发起 / 抄送我。  
详情：业务快照 + 步骤时间轴；同意 / 驳回（必填意见）/ 撤回。

### 5.7 列表筛选
默认：负责人、状态、创建时间、关键词。筛选状态写入 URL query（已实现关键词 `?q=`、
商机看板 `?view=&ownerId=&q=`，见 `hooks/useUrlState.ts`）；刷新、分享、浏览器回退均保留筛选。  
顶栏全局搜索调用 `GET /search`（补遗 §5）。

## 6. 前端工程约定

| 项 | 约定 |
|----|------|
| 目录 | `features/<module>/{api,components,hooks,pages}` |
| API 层 | 仅封装 fetch+类型 |
| 权限 | `useCan('opportunity:write')` 控制按钮 |
| 加载 | 表格/按钮 loading，防重复提交 |
| 错误 | 全局 message；401 跳登录 |
| 校验 | zod schema，与 shared 同源 |
| i18n | **禁止硬编码文案**；`react-i18next` + `locales/zh-CN.json` & `en-US.json` |
| 格式化 | 日期/数字/货币一律 `Intl`；禁止手写拼接 |
| 移动 | `<768` 底部 Tab；触控热区 ≥44px；详情操作用 Bottom Sheet |
| antd | `ConfigProvider` 注入 antd locale 随界面语言切换 |

> 完整多语言与手机端强制规格见 [10-i18n-mobile.md](./10-i18n-mobile.md)。

## 7. 空/错态文案
- 暂无数据 / 您没有查看该数据的权限 / 网络异常，请稍后重试 / 数据已被他人更新，请刷新后重试
